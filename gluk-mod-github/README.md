# Gluk / Глюк — Forge 1.20.1

Содержимое мода:
* NPC «Глюк» (яйцо призыва): модель Steve + твой скин, просто ходит.
* «Ошибка Бытия» (вкладка «Боевое снаряжение»): урон и скорость как у незеритового меча,
  бесконечная прочность. ПКМ на бегу — выпад как у копья, пробивает всех на пути.
* «Огненный артефакт» (ПКМ вкл/выкл): бесконечная огнестойкость, +10 урона каждым ударом,
  H — портал как у Незера, но без обсидиана (Верхний мир <-> Незер, мгновенный переход), X — телепорт по взгляду.
* «Артефакт молнии» (ПКМ вкл/выкл): защита от молнии, полёт (двойной прыжок),
  каждые 100 пройденных блоков +10% скорости (максимум 30 ступеней),
  при беге и полёте молнии бьют в игрока (только красиво, ничего не жгут) и летят искры.
Артефакт работает, пока лежит в инвентаре и включён. Клавиши H и X меняются в настройках управления.
Числа (бонус урона, дальность телепорта, шаг скорости) — в начале ArtifactLogic.java.

## Как получить .jar
Способ 1 (ничего не устанавливая): залей папку на GitHub →
вкладка Actions → build → внизу Artifacts → gluk-forge-1.20.1-jar.
Способ 2 (локально): JDK 17 + Gradle 8.8+, в папке проекта:  gradle build
Файл: build/libs/gluk-1.0.0.jar

## Установка
Minecraft 1.20.1 + Forge 47.x. Положи .jar в папку mods.
Если сборка пишет, что Forge 47.3.0 не найден, поменяй forge_version в gradle.properties
на любую версию 47.x с files.minecraftforge.net.

## Важно
Не заменяй файл assets/gluk/models/item/oshibka_bytiya.json чужими экспортами: координаты
модели должны быть от -16 до 32, а uv от 0 до 16. Иначе в игре будет фиолетовый куб.
Проверка запускается сама в GitHub Actions (scripts/validate_models.py).
